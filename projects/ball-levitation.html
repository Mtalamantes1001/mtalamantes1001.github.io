Ball-Levitation Control System

Personal Project · Model-Based Control (Simulink + Arduino)

Tools: Simulink · MATLAB · Arduino IDE · PID control · IR distance sensor · potentiometer

What?

This project is a closed-loop ball levitation system that uses an IR distance sensor and PWM-controlled blower to hold a ping-pong ball at a set height inside a tube. Built using Simulink model-based design with real-time embedded deployment to an Arduino for dynamic airflow control.

Pulse Width Modulation (PWM) is a technique that switches the blower's power on and off, where the proportion of "on" time sets its effective speed. It's the core control lever in this project: by adjusting the PWM duty cycle in real time, the controller fine-tunes airflow to hold the ball at its setpoint rather than running the blower at a single fixed speed.

How?

Using Simulink model-based design, I developed a control model that converts the nonlinear IR sensor voltage into position feedback for closed-loop regulation. From there, I implemented a PID-based controller to control the blower's PWM and stabilize the ball at multiple setpoints. The IR sensor, motor driver, and blower were interfaced through an Arduino, where the Simulink model was deployed for real-time testing. Finally,after turning the system and filtering out noise, I achieved instances where the ball would hold its position.

Diagram Setup

The model is built from three parallel strands feeding a summing block. The top strand sends a constant value of 1 to the digital pin, keeping the blower motor activated. The middle strand converts the potentiometer's height input into a velocity command, with an 8 cm offset added since my sesnor was hit and miss. The bottom strand uses a MATLAB function to turn the IR sensor voltage into a distance reading. The sum block then compares the setpoint and sensor distance to generate the control error that drives the airflow.

Results?

The system achieved stable levitation across multiple setpoints under real-time control, with validated distance conversion and reliable sensor feedback. Together these demonstrated effective closed-loop airflow regulation using Simulink embedded control, while giving me hands-on experience with PID tuning, sensor integration, and model-driven development.

Analysis

Together, the graphs demonstrate that the system was consistent for the intended application.
