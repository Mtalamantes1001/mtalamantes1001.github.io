Surveillance and Controllable Rover (SCR)

Personal Project · Remote-Controlled Rover (ESP32-CAM + Arduino)

Tools: SolidWorks · Arduino IDE · ESP32-CAM · HM-10 BLE · 2DOF pan/tilt servos · omnidirectional drive · 3D printing

What?

This project is a six-direction rover designed to integrate camera motion tracking, omnidirectional movement, and wireless video transmission that can be streamed to third-party web servers.

How?

  • Design: Created a two degree of freedom (2DOF) servo mount in SolidWorks, giving pan and tilt control for the camera system.
  • Integration: Incorporated an ESP32-CAM module for live streaming, motion-detection triggered recording, and SD card storage. Added an HM-10 BLE module for mobile control.
  • Programming: Developed the system code in Arduino IDE to host a URL website for First Person Video (POV).
  • Fabrication: Designed and 3D printed the servo mount for the camera module to ensure stable recording.

Servo Mount

The 2DOF pan/tilt mount was designed in SolidWorks and 3D printed. The exploded view shows the individual servos and printed brackets that make up the assembly; the assembled view shows the final pan-and-tilt configuration that carries and stabilizes the camera.

Results

Constructed a reliable omnidirectional rover capable of capturing and streaming video, with secure data logging accessible from 50 feet out.

The project reinforced skills in mechanical design, IoT communication, and embedded system programming, bringing them together into one controllable and responsive platform.

A practical application for this rover is remote surveillance — enabling safer assessment of dangerous environments while keeping the operator at a safe distance.
